## 🖊️ ¿Por qué LaTeX?

La elección de **LaTeX** sobre procesadores de texto convencionales refleja mi enfoque hacia la ingeniería:
1.  **Precisión:** Tipografía matemática perfecta para ecuaciones diferenciales y matrices.
2.  **Estructura:** Separación lógica entre contenido y formato.
3.  **Gestión Bibliográfica:** Referencias automáticas y trazables.
